CONFIGURATION

Upload parsing settings

There is no user authentication. Use a private SSH tunnel; anyone with access can upload logs and change settings or the issue library.

User activity parsing rules

Rules are tested from top to bottom; the first match wins. Every rule needs a named user group, and connection rules also need a named host group. Optional groups are ip and timestamp.

These rules extract users and hosts from uploaded messages.

(?P<user>...)(?P<host>...)(?P<ip>...)(?P<timestamp>...)

Common issues and resolutions

Matching is case-insensitive and looks for your phrase anywhere in a message. Remove timestamps and changing IDs from the phrase. This library is shared by analyser users.
